# Cosmos Learning Lab

A structured, hands-on learning environment for mastering the Cosmos SDK and the engineering principles behind institutional blockchain settlement.

## Learning contract

**Learn with GPT first; implement with Codex only after the relevant concept and design gate have been reviewed and approved.**

Every concept used in the learning journey must be documented here in a way that supports deep understanding, reproducible practice, and technical interviews. Documentation is part of the deliverable, not an afterthought.

## What belongs here

- Concept explanations and version-pinned source-code explorations
- Architecture and execution-flow diagrams
- Reproducible labs, commands, expected outcomes, and cleanup steps
- Failure experiments, troubleshooting, and recovery notes
- Tests and measured results, with environment and method recorded
- Security, performance, and operational implications
- Interview questions, answers, revision notes, and mastery evidence

## Repository map

- `docs/LEARNING_ROADMAP.md` — staged curriculum and learning gates
- `docs/DOCUMENTATION_STANDARD.md` — required structure and evidence rules
- `labs/` — reproducible exercises and experiments
- `diagrams/` — source files for architecture and sequence diagrams
- `interview/` — interview questions and answer notes
- `progress/` — mastery checklist and revision tracking

Directories will be added as their first substantive content is created.

## Evidence rules

- Pin framework/source claims to the exact release or commit studied.
- Distinguish verified facts from hypotheses and design proposals.
- Never invent command output, test results, benchmarks, or source paths.
- Record failures as well as successes, including how the result was verified.
- Keep labs repeatable on a clean environment wherever practical.

## Current status

Foundation setup. No Cosmos application implementation has started. Framework compatibility and the product architecture remain subject to explicit review before implementation.
